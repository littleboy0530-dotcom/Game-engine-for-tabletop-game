# Game engine for tabletop game

아이디어만 있으면 누구나 보드게임 MVP를 빠르게 만들고 재미를 검증할 수 있는 웹 기반 보드게임 프로토타이핑 엔진.

- 보드는 **존의 그래프**, 게임 규칙은 **루프 그래프**로 그린다.
- 노드와 말에 Lua 스크립트를 붙여 판정과 효과를 작성한다.
- 플레이 중에 루프 그래프에서 지금 진행 위치가 표시된다.

## 지금 들어 있는 게임
- 체스: 캐슬링, 앙파상, 승격, 체크메이트, 스테일메이트, 50수 규칙
- 장기: 상차림 선택, 궁성의 선, 포 규칙, 장군, 외통수
- 포커 (텍사스 홀덤): 블라인드, 베팅 라운드, 사이드 팟, 족보 판정, 손패 숨기기
- 작은 영지: 덱빌딩 메커니즘을 쓰는 오리지널 테스트 게임 (공급처, 액션/구매 단계, 공격 카드)
- 한 바퀴 부동산: 주사위로 도는 부동산 메커니즘의 오리지널 테스트 게임 (트랙 보드, 행운 카드, 통행료, 땅 팔기)
- 들썩들썩 경주: 레이서마다 능력(트리거)이 있는 오리지널 주사위 경주
- 마작 (간단 규칙): 론/퐁/치 반응 창구
- 별빛 시장: 중앙 줄 덱빌딩 오리지널 테스트 게임 (중앙 줄 자동 보충)
- 세 갈래 전선: 세 전선에 몰래 카드를 내는 오리지널 게임, 솔로 모드(스크립트 플레이어)
- 성곽 마을: 변을 맞춰 타일을 놓는 오리지널 게임 (열린 보드, 도시/길/수도원 점수)
- 층층 시장: 덮인 카드를 드러내며 가져가는 오리지널 피라미드 드래프트

## 실행

```bash
npm install
```
```bash
npm run dev
```

터미널에 나오는 주소(보통 `http://localhost:5173`)를 브라우저로 연다.

```bash
npm test
```

## 배포
`main` 브랜치에 올라가면 GitHub Actions가 테스트 후 GitHub Pages에 배포한다.
저장소 Settings → Pages → Source를 **GitHub Actions**로 설정해야 한다.
